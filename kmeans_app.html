How K-Means Works
01
Initialise Centroids
Randomly place k centroids in feature space using K-Means++ — smart seeding that spreads initial points for faster convergence.
02
Assign Points
Each customer is assigned to the nearest centroid using Euclidean distance in scaled RFM space.
03
Update Centroids
Each centroid moves to the mean position of all customers assigned to it in this iteration.
04
Repeat Until Convergence
Steps 2–3 repeat until no customer changes cluster, or max_iter is reached. Typically 10–50 iterations.
05
Label Segments
Sort clusters by mean Monetary value. Top cluster = Champions, lowest = Inactive. Apply business labels.

import pandas as pd from sklearn.preprocessing import StandardScaler from sklearn.cluster import KMeans from sklearn.metrics import silhouette_score # 1. Build RFM features rfm = df.groupby('CustomerID').agg( Recency =('InvoiceDate', lambda x: (snap-x.max()).days), Frequency=('Invoice', 'nunique'), Monetary =('Revenue', 'sum') ) # 2. Scale scaler = StandardScaler() X = scaler.fit_transform(rfm) # 3. Train km = KMeans(n_clusters=4, random_state=42, n_init=10) rfm['Cluster'] = km.fit_predict(X) # 4. Evaluate score = silhouette_score(X, rfm['Cluster']) print(f"Silhouette: {score:.3f}")
